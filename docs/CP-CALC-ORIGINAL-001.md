# Kalkulator Original

**Document ID:** `CP-CALC-ORIGINAL-001`  
**Version:** `4.3.0`

## Tujuan

Menyediakan kalkulator angka standar di dalam CalPro tanpa rumus bisnis khusus.

## Operasi

- Tambah, kurang, kali, dan bagi.
- Persen, tanda positif/negatif, koma desimal, hapus satu digit, dan reset.
- Input melalui tombol layar atau keyboard.

Pembagian dengan nol menghasilkan status `Error` dan dapat direset melalui tombol `AC`.
